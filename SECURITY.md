# Security policy

This repository holds a read-only measurement script and its configuration. It never writes to another repository
and holds no credentials; the scheduled workflow reads a token from a repository secret.

Report a vulnerability in the script or workflow through GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability). If that is unavailable, e-mail jason.han@jpl.nasa.gov with `[governance-checks
security]` in the subject. Reports are acknowledged within 3 business days. Do not include tokens or private
repository contents in a report.
